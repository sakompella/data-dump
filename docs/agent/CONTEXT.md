# Thought collection

A personal collection for remembering thoughts and intentions and recovering enough context to return to them.

## Language

**Thought**:
An idea, observation, question, or reflection worth keeping, whether complete or unfinished. Keeping a thought does not imply an obligation to act on it. A thought drawn from a ramble keeps a link back to that ramble.

**To-do**:
An action or possible action the user wants to remember to address. Inclusion does not require a firm commitment; tentative wording remains meaningful.

**Ramble**:
A contiguous stream of the user's writing or speech that may contain any number of thoughts, to-dos, or other material. A ramble ends when the user starts a new one or after a short period of inactivity.

**Split**:
Turning an ended ramble into thoughts by copying passages of the user's own words, unchanged. Only labels may be generated.
_Avoid_: summarize, extract, rewrite

**Synthesis**:
A generated account of captured material that helps the user recover its meaning. It is an interpretation, distinct from the user's original wording.

**Resurfacing**:
Bringing previously captured material back into view without requiring the user to remember to search for it.
